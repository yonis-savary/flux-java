# Flux-Java (WIP)

## Purpose of the project

The goal with this repository is 
- to learn Java+Angular ([Progress track here](./PROGRESS.md))
- gives a production-ready solution for freelancing accountability (French Financal System)



## Build the project

```
cp .env.example .env
make up
```

By default
- Backend : [`http://localhost:8080`](http://localhost:8080)
- Frontend : [`http://localhost:4200`](http://localhost:4200)

## Frontend

Build the API SDK

```
npm run openapi
```
